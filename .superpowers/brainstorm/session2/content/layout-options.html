How should we achieve "Full Size" without scroll bars?

The table currently has 12 columns. To remove the scroll bar, we need to decide how to handle the width.

A

Narrower Columns (Fit-to-Screen)

Reduce the width of each column so they all fit within your current browser window. No scrolling needed, but text might wrap more.

B

Wide Page (Full Natural Width)

Remove all width limits. The page will be as wide as the table needs to be. You won't have a scrollbar *inside* the table, but the whole page might scroll horizontally on small screens.

C

Vertical Layout (Transpose)

Put the Time slots as rows and Dates as columns. Since there are fewer dates than time slots (usually), it fits vertically on most screens better.
